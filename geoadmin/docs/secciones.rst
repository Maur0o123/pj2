Secciones
=========

Actualmente la plataforma se compone de cuatro grandes secciones funcionales visibles para el usuario:

- vehiculos
- sondajes
- prevencion de riesgos
- inventario

Adicionalmente existen módulos transversales de soporte que alimentan la operación principal, como equipos, documentación, API, mensajería y mantenedores base.

Los módulos implementados actualmente en el proyecto son:

- ``core``
- ``checklist``
- ``drilling``
- ``documentation``
- ``equipment``
- ``geoadmin``
- ``inventory``
- ``machine``
- ``maintenance``
- ``messenger``
- ``mining``
- ``offline``
- ``planning``
- ``prevencion``
- ``user``
- ``vehicle``
